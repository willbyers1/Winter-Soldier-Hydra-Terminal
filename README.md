# WINTER-01 // Asset WS-001 Mechanical Analysis & Control Terminal

An interactive Three.js and React engineering workstation modeling **Asset WS-001** (Winter Soldier Left Cybernetic Prosthetic Arm) with real-time 20-DOF kinematics, multi-mode WebGL visualization, deterministic telemetry/biomechanical simulation, and a custom GLB asset pipeline.

> **Disclaimer**: Unofficial fan-made engineering visualization project, not affiliated with Marvel or Disney. All biometric, telemetry, and diagnostic readouts are generated by a client-side deterministic simulation engine and make no medical claims.

---

## Key Features

### 1. Real-Time 3D Visualization (`@react-three/fiber` + Three.js)
- **GLB Mesh Pipeline (`public/models/winter-soldier-arm.glb`)**:
  - Automatically detects `UpperArm`, `LowerArm`, `GloveDetail`, and `Finger_0`..`Finger_14` nodes, normalizes millimeter coordinates to meters, and centers the horizontal left-arm assembly.
  - Welds split triangle vertices (`mergeVertices`) and computes `38°` creased normals (`toCreasedNormals`) alongside a per-vertex discrete Laplacian seam-cavity attribute (`aSeamCavity`) so curved armor plates stay smooth while overlapping plate steps stay crisp and mechanical.
  - Procedural **Red HYDRA Star** emblem projected onto the outer deltoid surface with a curved shader decal (`sdStar5`) and conformal star mesh.
  - Procedural **Cybernetic Shoulder Socket Bulkhead** sealing the proximal humeral cavity and **Tactical Inner Glove & Wrist Cuff** featuring a contoured metacarpal palm body, muscular thenar palm pad (`#14171c`), and cross-section-fitted inner finger sleeves.
- **Five Rendering Modes**:
  - **Exterior / Realistic PBR**: High-contrast brushed dark titanium `MeshPhysicalMaterial` (`#c4ccd4`, `metalness: 0.90`, `roughness: 0.22`, `clearcoat: 0.30`) with triplanar micro-grain, `#12161d` recessed seam darkening, `ACESFilmicToneMapping`, and a custom `PMREMGenerator` studio softbox environment.
  - **X-Ray**: Translucent electric-blue Fresnel shader (`AdditiveBlending`) with cyan `EdgesGeometry` overlays, internal robotic actuators, and crimson star highlight.
  - **Internal Structure**: Ghosted outer armor shell revealing fitted humeral/forearm struts, hydraulic pistons, wrist gimbal, and phalanx linkages.
  - **Wireframe**: Structural cyan/blue CAD crease edge lines over the studio void grid.

### 2. 20-DOF Articulated Kinematics & Hand Poses
- **Articulated Joints**:
  - **Arm & Wrist (5 DOF)**: Shoulder Pitch, Shoulder Roll, Elbow Flexion, Wrist Flexion, and Wrist Pronation/Supination computed from GLB `Box3` intersections.
  - **5-Digit Hand Rig (15 DOF)**: Spatial digit clustering relative to `GloveDetail` (`Thumb`, `Index`, `Middle`, `Ring`, `Little`), per-finger longitudinal axes (`rayDir`), local hinge axes (`normalize(cross(rayDir, palmNormal))`), and palmar joint pivots (`MCP` at `5%`, `PIP` at `42%`, `DIP` at `72%`).
- **Five Hand Pose Presets**:
  - `RELAX`: Native sculpted STL rest pose (`0°` deformation delta).
  - `OPEN`: Gentle negative uncurl (`-12° / -16° / -10°`) straightening fingers along their longitudinal plane.
  - `FIST`: Full palmar curl (`75° / 82° / 55°`) across the 4 fingers with the thumb adducted across the curled Index and Middle fingers.
  - `POINT`: Index extended straight forward (`-10° / -15° / -10°`), Middle/Ring/Pinky tightly curled (`75° / 82° / 55°`), and thumb folded over the curled Middle finger.
  - `THUMBS UP`: Four fingers closed into a fist with the thumb abducted straight upward (`+Y`) and `-18°` distal uncurl.

### 3. Terminal Modules & Telemetry
- **Eight Integrated Modules**: Overview & System Logs, Mechanical Analysis (with local GLB upload), Motion Control (joint sliders & pose presets), Diagnostics, Telemetry Charts, Failure Simulation (8 faults + E-STOP), and Configuration.
- **Interactive Viewport Tools**: Camera presets (`Default`, `Front`, `Side`, `Top`, `Hand`, `Wrist`, `Elbow`, `Shoulder`), component selection/isolation, exploded view slider, tactical glove toggle, and 3D point-to-point distance measurement tool.
- **Subject Analysis Dock**: 2D SVG anatomical torso overlay and real-time Canvas 2D traces for ECG, 3-channel EMG, Bus Voltage/Current, Power (W), and per-actuator load bars.

## Getting Started

### Prerequisites
- Node.js 18+ (or Bun)

### Installation
```bash
npm install
```

### Available Commands
```bash
npm run dev          # Start development server at http://localhost:3000
npm run build        # Build production bundle to dist/
npm run preview      # Preview production build
npm run lint         # Run TypeScript type check (tsc --noEmit)
npm run typecheck    # Run TypeScript type check (tsc --noEmit)
npm test             # Run Vitest unit, UI, and geometry tests
npm run inspect-stl  # Inspect raw STL files in models/
npm run build-arm    # Compile models/*.stl into public/models/winter-soldier-arm.glb
```
